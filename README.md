## 🖥️ Centauri64 — Build Your Own Games

**C# · MonoGame · Interpreter Development · Game Creation Tools · Networking**

[View the Centauri64 repository](https://github.com/chrisgilkes/centauri-64)

Centauri64 is a fictional 1980s home computer and game-creation environment, built from scratch using C# and MonoGame.

Inspired by the early days of home computing, it recreates the experience of learning to program, typing in magazine listings, experimenting with graphics and sound, and eventually creating your own games.

Rather than simply emulating an old computer, Centauri64 provides a complete fictional platform with its own programming language, runtime, development tools and progression system.

### Write Code. Make Games. Share Your Creations.

![Centauri64 BASIC editor](images/centauri64/basic-editor.png)

Players can write and run programs directly inside the computer using an integrated BASIC-style editor.

The underlying systems include:

- Custom BASIC tokenizer, parser and interpreter
- Interactive code editor with line-numbered programs
- Program execution, control flow, variables and subroutines
- SAVE / LOAD program management
- Custom bitmap-font rendering and virtual 320×200 display
- Graphics primitives, sprite rendering and animation
- Sound generation and keyboard input
- Integrated sprite, image and map editing tools
- Game creation challenges and career progression

### Create Games with Built-in Tools

![Centauri64 game running](images/centauri64/game-running.png)

![Centauri64 sprite editor](images/centauri64/sprite-editor.png)

The goal is to give players a self-contained game development environment where they can create artwork, write code, experiment with gameplay and build complete games without needing external development software.

### Networking and Multiplayer

![NetPong magazine cover](images/centauri64/netpong-cover.png)

Multiplayer is an important part of Centauri64's direction, exploring how networking can be made accessible through a simple programming language.

**NetPong** is a multiplayer Pong project intended to demonstrate how players can create connected games using the Centauri64 programming environment.

![NetPong gameplay](images/centauri64/netpong-gameplay.png)

The longer-term aim is to allow players to create, share and play games together, bringing the social side of home computing into a modern game-creation platform.

### Learn Through Retro Computing Magazines

![Centauri64 Issue 1](images/centauri64/issue-01-cover.png)

Centauri64 also features fictional home computing magazines inspired by the programming publications of the 1980s.

Each issue introduces new concepts through example listings, challenges and projects, encouraging players to learn by experimenting and modifying working programs.

The wider game includes a computer shop, software collection and career progression system, turning the experience of learning to program into a game of its own.

### Behind the Scenes

Centauri64 is also a personal engineering project exploring:

- Interpreter and runtime architecture
- Developer tooling and editing workflows
- Graphics and rendering systems
- Networking APIs for user-created games
- Data-driven content and persistence
- Performance and maintainability in C#

I'm particularly interested in how complex engine functionality can be exposed through simple, approachable tools that encourage experimentation and creativity.
