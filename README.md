## 🚀 Current Projects

### 🖥️ Centauri64

A retro-inspired fantasy computer/game system built from scratch in **C# and MonoGame**.

Centauri64 combines an interactive BASIC-style programming environment with graphics, sprites, sound and eventually multiplayer — exploring what a modern fantasy computer could look like while retaining the feel of 8-bit home computing.

**Current work includes:**

* BASIC tokenizer, parser and interpreter
* Program editing and execution
* SAVE / LOAD / DIR storage system
* Custom bitmap-font terminal renderer
* Virtual 320×200 display
* Graphics and sprite systems
* Input and controller APIs
* Expanding language and runtime
* Multiplayer planned

[View Centauri64](https://github.com/chrisgilkes/centauri-64)

### 🌌 Project Frontier

A new **procedural space exploration and civilisation simulation** built with **C# and MonoGame**.

Project Frontier explores the idea of a vast living galaxy rendered using text, glyphs and vector-style graphics rather than traditional sprite artwork.

The goal is a universe where players can discover planets and alien species, encounter procedurally generated civilisations, explore, trade and influence societies that continue to develop over time.

**Planned systems include:**

* Seeded procedural galaxies
* Star systems and planets
* Procedural alien species and civilisations
* Exploration and scanning
* First contact and alien languages
* Trading and ship progression
* Galactic history
* Civilisations that evolve over decades and centuries
* Fleet and armada encounters
* Persistent player discoveries

> *The universe is bigger than anything we could draw.*
